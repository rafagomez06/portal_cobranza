# React + Vite

# Crear el proyecto de cero

```bash
npm create vite@latest mi-proyecto-antd -- --template react
```

# Entrar y instalar dependencias

```bash
cd mi-proyecto-antd
```

# instalar dependencias

```bash
npm install
```

# Instalar Tanstack Query

```bash
npm i @tanstack/react-query

```

# instalar react router y framework ant desing

```bash
npm install antd react-router-dom
```

# Arrancar el proyecto

```bash
npm run dev
```
